# SyncX Web

Official website for SyncX (`skills/syncx`).

## Scripts
```bash
npm run dev
npm run lint
npm run build
npm run start
```

## Notes
- Built with Next.js App Router + TypeScript + Tailwind + GSAP.
- Content is centralized in `lib/content.ts`.
- Motion is managed via hooks in `hooks/` and respects `prefers-reduced-motion`.
